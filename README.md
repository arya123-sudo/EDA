# 📊 Exploratory Data Analysis — Practice Notebooks

A series of Jupyter notebooks from my data-analysis coursework, working through Python's data stack — from **NumPy fundamentals** (arrays, dtypes, array creation and random generation) into **exploratory data analysis (EDA) exercises**: loading data, inspecting it, cleaning it, and drawing conclusions from it.

EDA is the step where you actually understand a dataset before modelling — spotting missing values, outliers, skewed distributions and relationships between variables instead of blindly feeding raw data into an algorithm.

## 📂 Notebooks

| Notebook | Focus |
|---|---|
| `EDA.ipynb` | NumPy fundamentals — array creation, `dtype`, `zeros`/`ones`/`empty`, `arange` vs `linspace`, random arrays |
| `EDA3.ipynb` – `EDA7.ipynb` | Exploratory data analysis practice exercises |
| `Untitled74.ipynb` | Additional practice notebook |

## 🛠️ Tools

- **Python 3**
- **Jupyter Notebook**
- **NumPy** · **pandas** · **matplotlib**

## ▶️ How to Run

```bash
# Clone the repository
git clone https://github.com/arya123-sudo/EDA.git
cd EDA

# Install the data stack (if needed)
pip install numpy pandas matplotlib jupyter

# Launch Jupyter and open any notebook
jupyter notebook
```

The notebooks also open directly in **Google Colab** or **VS Code**.
